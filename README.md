# brew.jeon

개인 학습과 사이드 프로젝트를 정리하는 GitHub입니다.

Java/Spring 기반 백엔드 개발을 중심으로 공부하고 있으며,  
필요한 내용을 작은 예제나 프로젝트 형태로 구현하며 정리하고 있습니다.

## Projects

### brew-market

상품/게시글 기반 거래 서비스를 만들어보는 개인 프로젝트입니다.  
현재는 요구사항과 기본 구조를 정리하고, 백엔드부터 구현을 진행하고 있습니다.

- Backend: [brew-market-back](https://github.com/brewjeon/brew-market-back)
- Frontend: [brew-market-front](https://github.com/brewjeon/brew-market-front)

주로 살펴보는 내용은 다음과 같습니다.

- Spring Boot 기반 REST API 설계
- JPA 기반 도메인 모델링
- 사용자, 상품, 게시글 흐름
- React 기반 화면 개발
