# brew.jeon

개인 학습과 사이드 프로젝트를 정리하는 GitHub입니다.

Java/Spring 기반 백엔드 실무 경험을 바탕으로,
사이드 프로젝트에서 도메인 설계와 테스트, 데이터 처리 방식을 구현하며 정리하고 있습니다.

## Projects

### brew-market

지역 기반 거래 서비스를 만드는 개인 프로젝트입니다.
백엔드 API부터 단계적으로 구현하며, 데이터 무결성과 실패 조건을 테스트로 확인하는 데 집중하고 있습니다.

- Backend: [brew-market-back](https://github.com/brewjeon/brew-market-back)
- Frontend: [brew-market-front](https://github.com/brewjeon/brew-market-front)
- Dev Dashboard: [brew-market-dashboard](https://github.com/brewjeon/brew-market-dashboard) — 개발 로드맵과 진행 현황을 관리하는 React 대시보드

주로 살펴보는 내용은 다음과 같습니다.

- Spring Boot 기반 REST API 설계
- JPA 기반 도메인 모델링
- 입력값 검증, 공통 오류 응답과 DB 제약조건
- PostgreSQL 기반 통합 테스트와 GitHub Actions CI
- PostgreSQL / PostGIS 기반 위치 검색 설계 및 구현 계획
- React / TypeScript 기반 화면 개발

구현 현황과 실행 방법은 각 저장소의 README에 정리합니다. 대시보드의 진행 상태는 브라우저에 수동으로 기록하며, 실제 소스나 테스트 결과와 자동 동기화되지 않습니다.
